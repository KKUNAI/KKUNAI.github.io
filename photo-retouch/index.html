PROJECT PROPOSAL

내 사진의 색을
레퍼런스 한 장으로 완성하다

클로드와 함께 만드는 레퍼런스 기반 사진 보정 프로그램.
보정은 도구의 문제가 아니라 의도를 옮기는 일이라고 생각합니다.

01 · 목적

왜 만드는가

GOAL

보정을 더 쉽게

슬라이더를 하나씩 만지며 감을 찾는 시간을 줄이고, 촬영 의도에 집중할 수 있게 합니다.

REFERENCE A

다른 작품을 참고

마음에 든 작품의 색감과 톤을 분석해 내 사진에 가져옵니다.

REFERENCE B

내 사진을 참고

내가 가장 만족한 컷 한 장을 기준 삼아 다른 컷에도 같은 무드를 입힙니다.

현장에서 찍는 시간보다 책상 앞에서 색을 맞추는 시간이 더 길다면, 그 부분은 자동화할 가치가 있습니다.
02 · 필요한 기능

핵심 기능 3가지

FEATURE 1

라이트룸 수준의 보정

  • 노출·대비·하이라이트·섀도
  • 화이트밸런스, 색상별 HSL 조정
  • 톤 커브, 컬러 그레이딩, 선명도·노이즈
FEATURE 2

예시 사진 분위기 자동 적용

  • 예시 사진을 넣으면 톤과 색 분포를 분석
  • 내 사진에 맞는 보정값으로 자동 변환
  • 결과는 슬라이더로 다시 미세 조정
FEATURE 3

여러 장을 하나의 색감으로

  • 여러 장을 한 번에 처리
  • 같은 값 복사가 아니라 사진별로 다르게 계산
  • 조명이 달라도 결과물은 한 세트처럼
03 · 포토그래퍼의 시선

왜 같은 프리셋으로는 부족한가

같은 값, 다른 결과

실내 조명, 역광, 흐린 날은 원본 색이 전부 다릅니다. 프리셋을 그대로 붙이면 어떤 컷은 노랗고 어떤 컷은 푸르게 틀어집니다.

목표는 일관성

사진마다 보정값은 달라도 되고, 보는 사람이 느끼는 톤은 하나여야 합니다. 이것이 세트 작업의 기준입니다.

04 · 실제 사례

같은 예배 장소, 다른 톤

원본한 톤으로
CHURCH MINISTRY

교회 사역에도 바로 쓸 수 있습니다

같은 예배, 같은 조명이어도 컷마다 톤은 달라집니다. 연합예배나 행사 사진 수십 장을 한 번에 한 톤으로 맞추면, 소식지와 SNS에 올릴 때도 한 세트처럼 정돈된 느낌을 낼 수 있습니다. 사진 담당자의 보정 시간도 크게 줄어듭니다.

05 · 동작 방식

이렇게 작동합니다

1

레퍼런스 선택

작품 또는 내 사진 한 장

→
2

무드 분석

밝기 분포, 색 균형, 콘트라스트

→
3

사진별 보정값 계산

각 원본에 맞춰 개별 산출

→
4

확인과 미세 조정

비교 보기, 슬라이더로 마무리

자동 결과는 출발점이고, 최종 판단은 항상 촬영자의 눈이 합니다.

06 · 만들기 위한 약속

개발에서 지킬 원칙

원본은 건드리지 않기

비파괴 방식으로 보정값만 저장해 언제든 되돌릴 수 있게 합니다.

피부톤 보호

인물 사진에서 피부색이 무너지지 않도록 별도 가드를 둡니다.

결과 비교 필수

전후 비교와 레퍼런스 옆에 놓고 보기를 기본 화면에 둡니다.

작은 것부터

클로드와 단계별로 만들며, 먼저 한 장 보정 → 레퍼런스 → 일괄 순서로 갑니다.
